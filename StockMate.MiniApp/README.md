# StockMate Mini App

Telegram daxilində admin və işçi paneli kimi işləyən React/TypeScript tətbiqidir.

## Lokal işə salmaq

```powershell
npm install
npm run dev
```

Backend standart olaraq `http://localhost:5157` ünvanında gözlənilir. Fərqli ünvan üçün `.env.example` faylını `.env` adı ilə kopyalayıb `VITE_API_URL` dəyərini dəyişin.

Telegram xaricində açıldıqda tətbiq demo rejimində işləyir. İşçi görünüşünü lokal yoxlamaq üçün `?role=worker` əlavə edin.
